# MemoryScape

Describe a memory. Explore the 3D zone it becomes. Link zones into a walkable map of your past.

## Play

**https://eventhorizonstudio2027.github.io/MemoryScape/**

## Controls

- Click — look
- WASD — move
- E — enter portal
- Esc — release mouse

## Stack

Static Three.js app. No build step. Data in `localStorage`.
